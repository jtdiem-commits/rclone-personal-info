# Jim Personal rclone

Jim Personal rclone is a private-use desktop configuration of rclone for verifying files published to the owner's Google Drive.

It uses read-only Google Drive access to list files, inspect metadata, and download files for integrity checks. It cannot upload, modify, or delete Google Drive files through this read-only authorization.

Google authorization is completed by the owner. Credentials and authorization tokens are stored locally and are not published on this website.

This tool is for the owner's personal use and is not offered as a public service.
