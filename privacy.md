# Privacy Policy — Jim Personal rclone

Jim Personal rclone is a personal desktop tool used by its owner to verify files in the owner's Google Drive.

## Google Drive access

The tool requests read-only Google Drive access. It uses file names, folder information, file sizes, hashes where available, and downloaded file contents to check that published files arrived correctly.

This authorization does not permit uploading, modifying, or deleting Google Drive files.

## Data storage and sharing

OAuth credentials and authorization tokens are stored locally on the owner's computer. Downloaded verification files and logs may also be stored locally.

The tool does not send Google Drive data to this website, sell data, use it for advertising, or use it to train artificial intelligence models.

Google processes authentication and Drive requests. This public information website is hosted by GitHub Pages and does not request Google Drive access.

## Retention and control

The owner controls retention and deletion of local verification files, logs, and credentials. Access can be revoked through the owner's Google Account permissions.

## Contact

For questions, use the support email displayed on the Google consent screen for Jim Personal rclone.
